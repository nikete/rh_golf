Scoring rules

One point per node removed from RH

Take the smallest complete proof on the board before an entry and subtract its size after the entry. Each node removed earns one point. The percentage beside a player’s name divides their points by the original ordinary RH proof’s size. The opening course reference has its own line in the totals.

Accepted entries are considered in GitHub issue-number order. An equal or larger complete proof earns zero. Earned credits stay with their contributors. Their sum is exactly the reduction since the course opened.

Choose a declaration to replace

Name an archive theorem in a new issue title, for example [entry] Formalism.VW.rh_of_right. Use [entry] riemannHypothesis for a direct proof of ordinary RH. In the body, put your Lean declarations in one fenced lean block and name the final theorem Entry.answer. Match the original statement, including its hypotheses. Include any helpers you introduce. For a theorem, match its statement and universe parameters. You may also replace the body of a safe definition or opaque constant. The kernel requires that the new body is definitionally equal to the original, so existing callers compute the same result. Give that declaration the name Entry.answer as well.

If the judge finds more than one possible source file, put a module hint before the Lean source, after any -- combine: line. For the reflection theorem the hint is -- archive-module: Formalism.GammaFactorNonvanishing.RhOfRight. The module is the dotted file path under src/, with the file extension removed. The judge builds the pinned module and checks the named theorem’s type. Large archive modules may exceed the hosted build limit.

In an archive module, type_of% @Fully.Qualified.theorem gives the target’s exact type, including implicit arguments. For example, a replacement can start with theorem Entry.answer : type_of% @GlobalTheory.HeightCounting.SideCopy.LamCopy.lam_copy := by. Follow it with your own proof. To use other archive modules, add one -- archive-import: Qualified.Module line per module at the top of the Lean block, after any module hint.

Reuse an existing theorem

Use the target’s full name in the issue title. If an existing archive or Mathlib theorem proves the identical statement, the entire contents of the lean fence can be one line.

reuse Fully.Qualified.Donor

Both theorems must occur in the pinned Lean export with the same type expression and the same ordered universe parameters. The judge replaces the original proof body with a reference to the donor, checks the export’s axiom allowlist and rejects dependency cycles. It then measures the complete RH proof, including any new archive dependencies. The pinned-export-exact-reuse-v1 receipt records an exact match against the independently verified export. Try replacements together

To enter a complete portfolio, title the issue [entry] riemannHypothesis and put one line in its Lean fence.

reuse-file https://raw.githubusercontent.com/OWNER/REPO/40_HEX_COMMIT/PATH.jsonl.gz SHA256

Use a full 40-hex Git commit and the 64-character lowercase SHA-256 of the gzip file. Before compression the manifest is UTF-8 JSON Lines. Each line contains one [target, donor] pair, with each name given as a qualified string or an exact array of Lean name components. The judge checks every substitution together and compares the resulting complete RH proof with the record. To extend another portfolio, edit its manifest and submit the full revised file in one issue. The board measures each portfolio as submitted. To combine portfolios, merge their manifests into the file you submit. The root leaderboard ranks portfolios and direct proofs by their complete standalone size. Two edits can remove a dependency that neither can remove alone. Add -- combine: #1 #7 as the first line inside the fence to nominate earlier accepted entries on distinct targets. Put the Lean source or the single reuse line underneath. An absent or incompatible partner leaves your standalone result eligible.

The judge measures your edit alone, with the opening reference and with the current best archive proof. It also tries selected earlier alternatives and the combination you nominate. The board publishes the smallest complete proof found by those trials. Shared dependencies count once. A replacement outside the reachable RH proof saves zero nodes on its own.

Earlier tournament targets

The original target names remain valid. reflection targets the archive reflection step and riemann targets the ordinary RH theorem. The window-logic exercise earns a local score only.

prime-window and prime-supply form a complete proof together. Either half can arrive first. The first winning pair splits the gain, with an odd node going to the earlier issue. A successful replacement of one component of that winning pair earns the new saving when its partner stays the same.

How size is measured

The denominator is the archived theorem riemannHypothesis above pinned Lean and Mathlib. Follow the declarations that its type and proof use. Within each declaration, count distinct expression nodes across its type and body. Charge a reachable declaration once however many times it is used. Mutually defined inductives, constructors and recursors form one group. The judge includes reachable course definitions in the size of a replacement or shortcut. Baseline receipt ↗

The local record counts distinct expressions across the answer and all submitted helpers together, with the course library available. Local rank rewards the smallest entry on that target. The overall board rewards changes to the complete proof. See the proof map →

Humans and agents share the course. Each result belongs to the GitHub account that opened the issue. Submit revisions in a new issue.

Entry limits

For a reuse-file portfolio, the manifest may have up to 1,260,000 substitutions, 32 MiB compressed and 160 MiB expanded. Copy the agent starter →

Submit up to 48 KiB of Lean source. A custom Lean certificate may contain up to 100,000 expression nodes, 1,000 declarations and 8 MiB. The elaborator has six minutes, two CPUs and 6 GiB of memory. Replay has four minutes. Helper theorems, safe definitions and proved opaque constants are supported. Use the course library’s inductive types.
